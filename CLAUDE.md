# commission-calc — commission-calc.com

Сайт сети **TrafficJet** (моя компания): калькуляторы комиссии риелтора и real-estate инструменты (US, страницы по штатам `/state/<state>/` и городам `/commission/<city>/`).
Другие сайты сети: shopify-shipping-calc.com (флагман), commission-calc.com, shopify-fee-calc.com, supply-rank.com. Цель сейчас — рост прибыльности: доп. монетизация, email-база (~52k).

## Как работать со мной (Владислав)

**Выбор режима в начале каждой новой задачи** (кроме мелких правок — их просто делай):
- **А — «Сам»**: минимум вопросов, сам формируешь решение и доводишь до цели; принятые решения — списком в конце.
- **Б — «Вместе»**: сначала через вопросы и диалог формируем, что строим, зачем и каким путём (вопросы — лучше вариантами на выбор), потом делаешь.
Уточняющие вопросы задавать можно, если ответ меняет результат.

**Стиль:**
- Общение на русском. Код, коммиты, комментарии, описания PR — на английском (описание PR можно продублировать кратко по-русски).
- Коротко: сначала результат, потом 2–5 строк — что изменилось и почему.
- Часто работаю с iPad без терминала: всё, что нужно сделать руками, — пошагово через веб-интерфейсы (GitHub, Cloudflare, панели хостинга).

**Самостоятельность:**
- После выбора режима — максимально сам: читай код, запускай сборку/тесты, проверяй.
- Остановись и спроси перед необратимым: прод-деплой, миграции/удаление данных, DNS, смена URL индексируемых страниц, force-push.
- Не выдумывай API, версии, факты — проверяй.
- Секреты (ключи, токены, seed, .env) — никогда в код, коммиты и логи.

## Стек и деплой
- Astro (`output: 'static'`) + Tailwind + `@astrojs/sitemap`; хостинг Cloudflare Pages.
- `functions/` — Cloudflare Pages Functions: `_middleware.js` (301 www → без www), `api/subscribe.js` (подписка на email).
- `public/_redirects`, `public/_headers` — редиректы/заголовки Cloudflare.
- Данные: `src/data/*.ts`; блог: `src/content/blog/*.md` (content collections).

## Команды
- `npm install` · `npm run dev` · `npm run build` (сборка обязана проходить перед PR) · `npm run preview`.

## SEO-правила
- В `astro.config.mjs` есть remark-плагин, удаляющий ссылки блога на несуществующие корневые страницы. **Добавил новую корневую страницу → внеси её slug в `REAL_ROOT_PAGES`**, иначе ссылки на неё будут вырезаны.
- Тонкие программные страницы → `noindex,follow` и исключать из sitemap.
- Не менять URL индексируемых страниц и не добавлять редиректы без спроса.
- В PR: что изменено, зачем и какую метрику GSC ждём (Crawled – not indexed / Not found 404 / Page with redirect / позиции / CTR).
- Контент — на английском (US), без воды; цифры (тарифы, комиссии, ставки) — только из проверяемых источников, с указанием года.
